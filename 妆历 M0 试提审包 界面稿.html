1这份文件怎么用

照着敲代码用。两张主屏是提审截图要拍的，6 个壳页面是让审核员点不白的。 真正的工量不在画页面，在 §5 可点性清单 —— 每一个能点的地方都要有合理响应。

📌 M0 的交付标准（唯一一条）
「审核员能走完一条完整路径，中途没有任何一处白屏、崩溃或死链。」
⚠️ 提审最常见的驳回理由之一是「功能不完整」。审核员点到空白页 = 态度问题，不是「功能少」的问题。

1.2 两道防线（M0 同样生效，不因「最小版本」放宽）

防线 ① · 全顾客端零金额
落地页 / 填表页 / 我的预约，一个 ¥ 都不许有。
个人主体可以有金额（「记账」就是消费记录），违规的是「构成一次服务要约 + 分享给顾客看」。
→ 妆位表不带价格字段，定金只标「已收 / 未收」。
防线 ② · 零社交特征
妆面样片区没有点赞、评论、收藏、浏览数、转发数，没有「更多作品」入口。
个人主体没有「社交」类目，而「工具-图片处理」明写「如提供传播和公开访问服务，属于社交范畴」。
→ 落地页的叙事是「这个化妆师的个人页」，不是作品广场。
⚠️ M0 最容易犯的三个错（因为它们都长得像「正常功能」）：
① 加「邀请同行」——多商户入驻最直接的证据，M0 更容易犯，因为它最像增长手段；
② 加「浏览所有化妆师」入口——立刻是平台；
③ 提审备注里写「平台」二字——这就是上次驳回的直接根因。

3.1 分享：只用微信自带的，我们不做任何分享 UI

✅ 不做自定义分享面板。微信原生分享（右上角「···」→ 转发，或页面里一个 <button open-type="share">）已经包含选聊天、转发、生成图片等全部能力。 自己画一个只会更差，而且审核看到「诱导分享」还会额外找麻烦。
📌 所以规格书里那 4 处「分享」（A1 快捷操作 / A4 卡片行尾 ×2 / A5 底栏）本来也只是触发按钮，没有一处是要画面板的。
项口径
触发方式① 用户点右上角「···」→ 转发；② 页面里放一个 <button open-type="share">，用户点它。
⚠️ 小程序没有能从 JS 主动唤起转发的 API（wx.shareAppMessage 是小游戏的，小程序里不适用）→ 所以按钮必须存在，否则只能靠用户自己去点右上角。
「写那个代码」写在哪页面级 JS，不是云函数：
Page({ onShareAppMessage() { return { title, path, imageUrl } } })
唯一算后端活的只有 path 里那个 artist_id —— 由 C1 拿去调云函数拉 artists / slots。
卡片返回什么title =「示例的妆位 · 示例漫展」
path = /pages/landing/landing?artist_id=demo
imageUrl = 第一张样片，比例 5:4
按钮样式<button> 是原生组件，自带的 border / background / ::after 会给按钮套一层灰边，跟我们的 .btn 打架，必须重置：
border:none;background:transparent;line-height:normal + button::after{border:none}。这十几行是必写的。
⚠️ 原生分享带来一个 M0 必须解决的问题：审核员怎么走到 C1？
C1 是提审截图要拍的屏，可它的唯一入口是分享卡片 —— 没有谁能分享给审核员。
解法正好是原生分享：审核员以化妆师身份进小程序 → 新建档期 → 点【分享我的妆位】→ 转发给「文件传输助手」 → 从聊天里点开卡片 → 进 C1。
这是自助的，不依赖我们的任何自定义 UI。
→ 代价：M0 里必须有一个 open-type="share" 按钮（已加在壳 5 底栏，见 §6 第 14 项）。
→ 📌 同时在提审备注里写明顾客端页面路径 /pages/landing/landing?artist_id=demo，双保险。
🔴 M0 明确不做 onShareTimeline（分享到朋友圈）—— 这不是省事，是避坑。
朋友圈点开进的是「小程序单页模式」，在那个模式下：
① 所有路由 API 被禁用（navigateTo / redirectTo / switchTab / reLaunch / navigateBack）→ 【选这个妆位】点不动，只会弹「请前往小程序使用完整服务」；
② 没有登录态，wx.login 不可用，云开发资源要开「未登录访问」才读得到 → C1 是要拉 artists / slots 的，会白屏（进单页模式时场景值 1154）。
→ 这正好同时踩中 M0 最怕的两件事：点了没反应 + 白屏。
→ 真要朋友圈，得单独做一个「单页模式展示版」落地页。M0 不做，M1 之后再评估。

最容易被忽略的是第三条：审核员点进「我的作品」发现只有一片空白且没有返回，会以为卡死了。

1「邀请同行」/「邀请有奖」多商户入驻最直接的证据。M0 更容易犯 —— 因为它最像「增长手段」

5「更多作品」/ 作品列表页入口红线 1。可枚举入口 = 公开内容区
6漫展名做成平台维护的枚举字典红线 3。必须是自由文本。做成「展会页」= 双违规

8.1 🔴 M0 提审的两件「后台动作」——跟代码无关，但漏了就提不了审

① 《用户隐私保护指引》要配置并发布 —— 填表页收集微信号 / 紧急联系方式，属于采集用户信息。
② 提审时「是否采集用户隐私」必须勾「采集」 —— 官方文档写明：勾了「未采集隐私」或未声明隐私协议，平台会回收接口调用权限。 报错长这样：fail appid privacy api banned（权限被回收）；errno 112（用了某个隐私类型但没在指引里声明，补齐后约 5 分钟生效）。
✅ 好消息：M0 不需要画「隐私授权弹窗」，不加屏。
那个弹窗只在调用隐私接口 / 组件（chooseMedia / chooseAvatar / getLocation 等）时才触发； M0 全是手输 <input> + 假数据，一个都不碰。
⚠️ 但 M1 一旦做化妆师上传头像 / 样片（chooseMedia），弹窗就必须做 —— 那时要注册 wx.onNeedPrivacyAuthorization 自己画，或用平台默认弹窗。
